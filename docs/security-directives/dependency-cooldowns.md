# Dependency cooldowns

Do not download a package version onto your laptop before its seven-day cooldown
ends because of the supply-chain security risk. Instead, escalate to `#security`
on Slack and consult [Dependency cooldown exceptions](https://app.notion.com/p/3f12fa20e38681c4bf18e5fd27b1efc7?pvs=204) for the latest guidance.
